### Sample Questions

#### Multiple Choice

1. What is the correct way to define an API route in Laravel?

```php
// A)
Route::get('/users', 'UserController@index');

// B)
Route::get('/users', [UserController::class, 'index']);

// C)
get('/users', [UserController::class, 'index']);

// D)
A and B are both correct
```

**Correct Answer**: D

---

2. Which Vue.js pattern is recommended for reusable logic?

- [ ] Vue Mixins
- [x] Vue Composables
- [ ] Vue Directives
- [ ] Vue Filters

**Correct Answer**: B

---

3. What is the purpose of eager loading in Eloquent?

- [ ] To improve query performance
- [x] To prevent N+1 queries
- [ ] To encrypt data
- [ ] To cache results

**Correct Answer**: B

---

#### Code Analysis

Analyze the following code and identify issues:

```php
public function update(Request $request, $id)
{
    $user = User::find($id);
    $user->name = $request->name;
    $user->save();
    return $user;
}
```

**Issues to identify**:
- [x] No authorization check
- [x] No input validation
- [x] No error handling for null user
- [x] Missing resource response

---

#### Implementation Tasks

**Task 1**: Create an API endpoint for a new resource

Requirements:
- Create model, migration, controller
- Define CRUD routes
- Create resource transformer
- Write unit tests

**Task 2**: Create a Vue component

Requirements:
- Use TypeScript
- Implement props and emits
- Add proper typing
- Write component tests

**Task 3**: Add analytics tracking

Requirements:
- Create event definition
- Implement tracking call
- Write query to retrieve data

## Certification Information

### Certification Levels

| Level | Requirements | Validity |
|-------|--------------|----------|
| Alumate Certified User | User assessment 80%+ | 2 years |
| Alumate Certified Admin | Admin assessment 80%+ + User cert | 2 years |
| Alumate Certified Developer | Dev assessment 80%+ + Admin cert | 2 years |

### Certification Process

1. Complete all required training modules
2. Pass all hands-on exercises
3. Pass certification assessment
4. Submit certification application
5. Receive digital certificate

### Recertification

- Complete recertification training
- Pass updated assessment
- Pay recertification fee

### Certification Benefits

- Recognition of expertise
- Career advancement opportunities
- Access to certified-only resources
- Priority support access

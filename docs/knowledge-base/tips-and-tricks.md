## Navigation Shortcuts

### Quick Access Menu

Access frequently used features instantly:

| Shortcut | Action |
|----------|--------|
| Press `Q` | Quick search anywhere |
| Press `G` then `U` | Go to Users |
| Press `G` then `E` | Go to Events |
| Press `G` then `A` | Go to Analytics |
| Press `G` then `S` | Go to Settings |
| Press `?` | Show all shortcuts |

### Sidebar Navigation Tips

- **Pin favorites**: Click the pin icon on any sidebar item to keep it at the top
- **Collapse sections**: Click section headers to minimize
- **Recent items**: Sidebar shows your 5 most recently accessed items

### Breadcrumb Navigation

Use breadcrumbs for quick navigation:

```
Home > Users > All Users > John Doe > Edit Profile
```

Click any breadcrumb level to jump directly to that section.

## Search Tips

### Advanced Search Operators

Get precise results with these operators:

| Operator | Example | Result |
|----------|---------|--------|
| `exact:"John Doe"` | `exact:"John Doe"` | Exact match only |
| `year:2020` | `year:2020` | Filter by graduation year |
| `has:phone` | `has:phone` | Only records with phone |
| `has:photo` | `has:photo` | Only records with photos |
| `in:active` | `in:active` | Filter by status |
| `from:last_week` | `from:last_week` | Date filter |

### Search Modifiers

| Modifier | Example | Description |
|----------|---------|-------------|
| `NOT` | `NOT admin` | Exclude matches |
| `OR` | `2020 OR 2021` | Multiple values |
| `AFTER` | `AFTER:2020-01-01` | Date filter |
| `BEFORE` | `BEFORE:2023-12-31` | Date filter |

### Save Searches

1. Perform your search
2. Click **"Save Search"** above results
3. Enter a name
4. Access saved searches from the search bar dropdown

## Profile Hacks

### Bulk Profile Updates via CSV

Update multiple profiles efficiently:

1. Export current profiles
2. Edit the CSV (keep headers!)
3. Only include changed fields
4. Import using **Admin → Data → Import**
5. Select **"Update Existing Records"**

### Profile Photo Best Practices

| Tip | Details |
|-----|---------|
| File size | Max 5MB |
| Dimensions | 400x400 pixels recommended |
| Format | JPG or PNG |
| Quality | High quality, not blurry |

### Rich Text in Bio

Use formatting in your profile bio:

| Formatting | Syntax | Example |
|------------|--------|--------|
| Bold | `**text**` | **Bold** |
| Italic | `*text*` | *Italic* |
| Line breaks | `\n` | New line |
| Bullet points | `-` | • List item |
| Links | `[text](url)` | [Link](https://...) |

### Quick Add Experience

1. Hover over your profile
2. Click **"Quick Add"** (appears on hover)
3. Select **"Experience"** or **"Education"**
4. Fill in the popup form
5. Changes save automatically

## Analytics Tips

### Date Range Shortcuts

Use relative date ranges for faster reporting:

| Shortcut | Result |
|----------|--------|
| `today` | Current day |
| `this_week` | Current week |
| `this_month` | Current month |
| `this_quarter` | Current quarter |
| `this_year` | Current year |
| `last_30` | Last 30 days |
| `ytd` | Year to date |

### Custom Date Presets

1. Go to any analytics view
2. Click date range picker
3. Select **"Custom"**
4. Enter your dates
5. Click **"Save as Preset"**
6. Name it (e.g., "Fiscal Year")

### Chart Customization

Click on any chart to access customization:

| Action | How |
|--------|-----|
| Change type | Click chart type icon |
| Add filter | Click filter icon |
| Add comparison | Click "Compare" |
| Export image | Right-click → Save |
| View data | Click "Data Table" |

### Drill-Down Analytics

Click on any chart element to drill down:

1. Bar/column → View details by category
2. Line point → View specific data point
3. Pie slice → Filter to that segment
4. Table cell → View record details

## Productivity Tips

### Notification Management

Prioritize what you see:

1. Click notification bell
2. Click **"Settings"**
3. Configure notification types:
   | Type | Options |
   |------|---------|
   | Mentions | Real-time, Digest, Off |
   | System | Real-time, Digest, Off |
   | Digest | Daily, Weekly, Never |

4. Set email vs. in-app preferences
5. Use "Do Not Disturb" mode (9 PM - 7 AM)

### Email Digest Optimization

Customize your email digest:

1. Go to **Settings → Notifications → Email**
2. Click **"Configure Digest"**
3. Select sections to include:
   - Activity summary
   - Notifications
   - Suggested connections
   - Upcoming events
   - Trending discussions
4. Choose delivery time
5. Save preferences

### Quick Actions Menu

Access common actions faster:

1. Press `Q` to open quick actions
2. Type action name
3. Select from results

**Available Quick Actions:**
- "New user"
- "Create event"
- "Export report"
- "Send email"
- "Add note"

### Undo Actions

Made a mistake? Act quickly:

| Action | Undo Window | How |
|--------|-------------|-----|
| Record deletion | 10 seconds | Banner appears |
| Field edit | Until saved | Ctrl+Z |
| Bulk operation | 30 seconds | Contact support |
| Email send | Until sent | Recall option |

## Hidden Features

### Developer Mode

For advanced users:

1. Open browser console
2. Type: `localStorage.setItem('devMode', 'true')`
3. Refresh page
4. Access hidden tools in footer

**Features unlocked:**
- Raw API response viewer
- Performance metrics
- Debug logs
- Feature flags

### URL Shortcuts

Direct links to common views:

| URL | Opens |
|-----|-------|
| `/users` | Users list |
| `/users/search` | Advanced search |
| `/analytics/dashboard` | Analytics home |
| `/events/calendar` | Event calendar |
| `/settings/profile` | Profile settings |
| `/reports/custom` | Custom reports |

### Batch Processing

Process multiple items at once:

1. Enable batch mode (toggle in list view)
2. Select multiple items
3. Choose action:
   - Export
   - Add tags
   - Send email
   - Update fields
4. Apply to all selected

### Dark Mode

Enable dark theme:

1. Go to **Settings → Appearance**
2. Select **"Dark"** or **"System"**
3. Optionally set schedule (6 PM - 6 AM)

## Time-Savers

### Template Usage

Create reusable templates:

1. **Email Templates**
   - Go to **Settings → Templates**
   - Click **"Create Template"**
   - Use merge tags: `{{first_name}}`, `{{last_name}}`, `{{year}}`
   - Save for future use

2. **Report Templates**
   - Create a report
   - Click **"Save as Template"**
   - Use for recurring reports

3. **Event Templates**
   - Create event with standard settings
   - Save as template
   - Duplicate for new events

### Quick Filters

Save frequently used filters:

1. Apply filters to a list
2. Click **"Save Filter"**
3. Name it
4. Access from filter dropdown

**Example saved filters:**
- "Active donors 2023"
- "Recent graduates seeking jobs"
- "Local chapter members"

### Drag-and-Drop Anywhere

Move items with drag and drop:
- Reorder sidebar items
- Drag emails to folders
- Drop files in uploads
- Arrange dashboard widgets

### Auto-Save Drafts

Never lose work:

1. Most forms auto-save drafts every 30 seconds
2. Return to incomplete forms later
3. Drafts saved for 30 days
4. Access from **"My Drafts"** in profile

### Quick Copy

Copy information instantly:

| Action | How |
|--------|-----|
| Copy link | Click copy icon on URLs |
| Copy cell | Right-click → Copy |
| Copy record | Click "Copy" on record |
| Copy email | Click "Copy" on contact |
| Copy all | Select all → Copy |

## Mobile App Tips

Access key features without internet:

1. Enable offline mode in app settings
2. Sync data when connected
3. View cached:

### Quick Actions

Swipe gestures on mobile:

| Swipe | Action |
|-------|--------|

| Right on item | Mark as read/Complete |
| Down | Refresh |
| Up | Load more |

Use voice for hands-free actions:

- "Find [name]"
- "Send email to [name]"
- "Add note"
- "Create event"
- "Show my notifications"

## Account Management

### How to Reset Your Password

1. Go to the Alumate login page
2. Click **"Forgot Password"** link below the login form
3. Enter your registered email address
4. Click **"Send Reset Link"**
5. Check your email (including spam folder)
6. Click the reset link in the email
7. Enter your new password (minimum 8 characters)
8. Click **"Reset Password"**
9. Log in with your new password

**Password Requirements:**
- At least 8 characters
- One uppercase letter
- One lowercase letter
- One number
- One special character

### How to Enable Two-Factor Authentication

1. Log in to your Alumate account
2. Navigate to **Settings → Security**
3. Click **"Enable Two-Factor Authentication"**
4. Download an authenticator app (Google Authenticator, Authy, etc.)
5. Scan the QR code displayed on screen
6. Enter the 6-digit code from your authenticator app
7. Click **"Verify and Enable"**
8. Save your backup codes in a secure location
9. Click **"I have saved my backup codes"** to complete

**Important:** Backup codes can only be used once. Store them safely.

### How to Update Your Email Address

1. Go to **Settings → Profile**
2. Click **"Change Email"** next to your email address
3. Enter your new email address
4. Click **"Send Verification"**
5. Check your new email for verification link
6. Click the verification link
7. Confirm the change

**Note:** You will be logged out and must log in with your new email.

## Profile Setup

### How to Complete Your Profile

#### Step 1: Basic Information
1. Click your profile picture or name
2. Select **"Edit Profile"**
3. Fill in:
   - Full name
   - Preferred name
   - Pronouns
   - Headshot photo
   - Bio/About section

#### Step 2: Education History
1. Scroll to **Education** section
2. Click **"Add Education"**
3. Enter:
   - Institution name
   - Degree type
   - Field of study
   - Graduation date
   - Activities and honors

#### Step 3: Professional Information
1. Scroll to **Experience** section
2. Click **"Add Experience"**
3. Enter:
   - Job title
   - Company/organization
   - Location
   - Start and end dates
   - Description

#### Step 4: Skills and Interests
1. Scroll to **Skills** section
2. Add relevant skills
3. Select interests from dropdown
4. Indicate availability for mentoring

#### Step 5: Contact Information
1. Scroll to **Contact** section
2. Update phone number
3. Add social media links
4. Set preferred contact method
5. Click **"Save Changes"**

### How to Set Profile Visibility

1. Go to **Settings → Privacy**
2. Scroll to **Profile Visibility**
3. Choose visibility level:

| Option | Description |
|--------|-------------|
| Public | Anyone can view |
| Members Only | Logged-in users only |
| Connections | Your connections only |
| Private | Only you |

4. Configure visibility for each section
5. Click **"Save Changes"**

### How to Connect with Classmates

1. Use the **"Find Alumni"** search (main navigation)
2. Enter search criteria:
   - Graduation year
   - Degree/Major
   - Location
   - Company
3. Browse results
4. Click **"Connect"** on a profile
5. Add optional personal message
6. Click **"Send Request"**

**Tip:** A personalized message increases connection acceptance rates.

## Analytics & Reports

### How to Create a Custom Report

1. Navigate to **Analytics → Reports**
2. Click **"Create New Report"**
3. Select report type:
   - User Activity
   - Engagement Metrics
   - Demographic Analysis
   - Custom Query
4. Choose metrics to include:
   | Category | Available Metrics |
   |----------|-------------------|
   | Users | Total, Active, New, Retained |
   | Engagement | Logins, Sessions, Events |
   | Demographics | Location, Year, Degree |
   | Custom | Select fields |

5. Set filters:
   - Date range
   - User segments
   - Activity types
6. Choose visualization:
   - Line chart
   - Bar chart
   - Pie chart
   - Table
7. Click **"Generate Report"**
8. Save report for future use (optional)
9. Export results (CSV, PDF, Excel)

### How to Schedule Automated Reports

1. Create or open a report
2. Click **"Schedule"** button
3. Set frequency:
   | Frequency | Options |
   |-----------|---------|
   | Daily | Every day, Weekdays only |
   | Weekly | Day of week, Time |
   | Monthly | Day of month, Time |
   | Quarterly | Month, Day, Time |

4. Enter recipient email addresses
5. Choose export format (PDF, CSV, Excel)
6. Click **"Save Schedule"**

### How to Export Analytics Data

1. Open any analytics view or report
2. Click **"Export"** button (top right)
3. Select format:
   - **CSV**: Spreadsheet compatible
   - **Excel**: With formatting
   - **PDF**: Print-ready
   - **JSON**: For API use
4. Choose data range (if prompted)
5. Click **"Generate Export"**
6. Download when ready

**Tip:** Large exports are sent via email for files over 10MB.

## Event Management

### How to Create an Event

1. Navigate to **Events → Create Event**
2. Fill in basic information:
   | Field | Description |
   |-------|-------------|
   | Event Name | Title of your event |
   | Type | Reunion, Networking, Workshop, etc. |
   | Description | Event details and agenda |
   | Date & Time | Start and end time |
   | Location | Physical or virtual address |

3. Set registration options:
   - Registration required?
   - Capacity limit
   - Registration deadline
   - Waitlist enabled?

4. Configure virtual event (if applicable):
   - Platform (Zoom, Teams, etc.)
   - Join link
   - Recording settings

5. Add event image or graphic
6. Set visibility:
   - Public
   - Members only
   - Specific segments
7. Click **"Publish Event"**

### How to Manage Event Registrations

1. Go to **Events** and select your event
2. Click **"Registrations"** tab
3. View registration list:
   | View | Description |
   |------|-------------|
   | All | Complete registration list |
   | Confirmed | Approved registrations |
   | Pending | Awaiting approval |
   | Waitlist | Beyond capacity |

4. Approve/Deny registrations:
   - Select registrations
   - Click **"Approve"** or **"Deny"**
   - Add optional note

5. Export registration list:
   - Click **"Export"**
   - Choose format (CSV, Excel)
   - Download

6. Send communications:
   - Click **"Email Attendees"**
   - Select template or write custom
   - Send

### How to Track Event Attendance

1. Open event details
2. Navigate to **Attendance** tab
3. Options for tracking:

| Method | Description |
|--------|-------------|
| QR Code | Scan attendee QR codes |
| Manual Check-in | Staff marks attendance |
| Auto-check-in | Virtual event attendance |

4. View attendance report:
   - Total registered
   - Total attended
   - No-show rate
   - Check-in times

5. Export attendance data for records

## Data Management

### How to Import Data via CSV

1. Prepare your CSV file:
   - Use provided template
   - Include required headers
   - Validate data formats

2. Navigate to **Admin → Data → Import**
3. Click **"Upload CSV"**
4. Select your file
5. Map fields:
   | CSV Column | Alumate Field |
   |------------|---------------|
   | email | Email Address |
   | first_name | First Name |
   | last_name | Last Name |
   | grad_year | Graduation Year |

6. Review mapping
7. Set import options:
   - Update existing records?
   - Skip invalid records?
   - Send welcome emails?

8. Click **"Preview Import"**
9. Review preview and errors
10. Click **"Confirm Import"**
11. Monitor import progress

### How to Export User Data

1. Go to **Admin → Users → Export**
2. Select export type:
   - All users
   - Filtered users
   - Specific segments
3. Choose fields to export:
   | Field Group | Options |
   |-------------|---------|
   | Profile | Name, Email, Phone |
   | Education | Degree, Year, Major |
   | Professional | Company, Title |
   | Engagement | Last login, Activities |

4. Select format (CSV, Excel, JSON)
5. Click **"Generate Export"**
6. Download when ready

### How to Bulk Update Records

1. Navigate to the records list
2. Apply filters to select records
3. Click **"Bulk Actions"**
4. Select action:
   | Action | Description |
   |--------|-------------|
   | Update Fields | Change specific fields |
   | Add Tags | Add tag(s) to records |
   | Remove Tags | Remove tag(s) |
   | Export | Export selected records |
   | Delete | Remove selected records |

5. Configure action details
6. Review and confirm
7. View results

## Integrations

### How to Connect a CRM Integration

1. Navigate to **Settings → Integrations**
2. Find CRM section
3. Click **"Configure"** for your CRM
4. Enter credentials:
   | Field | Description |
   |-------|-------------|
   | API Key | Your CRM API key |
   | Instance URL | Your CRM instance URL |
   | Username | Integration username |

5. Click **"Test Connection"**
6. Configure field mappings
7. Set sync options:
   - Sync frequency
   - Data direction
   - Conflict resolution
8. Click **"Save Configuration"**

### How to Set Up Webhooks

1. Go to **Settings → Integrations → Webhooks**
2. Click **"Add Webhook"**
3. Enter webhook details:
   | Field | Description |
   |-------|-------------|
   | Name | Descriptive webhook name |
   | URL | Endpoint URL |
   | Events | Select events to trigger |

4. Select events to subscribe to:
   - User.created
   - User.updated
   - Event.registration
   - Donation.received
   - etc.

5. Configure security (optional):
   - Secret key
   - Signature algorithm
6. Click **"Save Webhook"**
7. Test webhook with sample payload
8. Monitor deliveries in logs

### How to Configure Single Sign-On (SSO)

1. Navigate to **Settings → Security → SSO**
2. Select SSO provider:
   - SAML 2.0
   - OAuth 2.0
   - OpenID Connect
3. Enter provider configuration:
   | Setting | Description |
   |---------|-------------|
   | Client ID | Provider application ID |
   | Client Secret | Provider secret |
   | Issuer | Provider URL |
   | Metadata URL | SAML metadata URL |

4. Configure attribute mapping:
   | Alumate Field | Provider Attribute |
   |---------------|-------------------|
   | Email | http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress |
   | First Name | givenname |
   | Last Name | surname |

5. Enable SSO for users:
   - All users
   - Specific roles only
   - Invitation only
6. Click **"Save Configuration"**

## Administration

### How to Create a New User

1. Navigate to **Admin → Users**
2. Click **"Add User"**
3. Enter required information:
   | Field | Required? |
   |-------|-----------|
   | Email | Yes |
   | First Name | Yes |
   | Last Name | Yes |
   | Role | Yes |

4. Select role:
   - Admin
   - Staff
   - User
   - Custom role

5. Configure permissions (if custom role)
6. Set user status:
   - Active
   - Pending email verification
   - Disabled

7. Click **"Create User"**
8. User receives welcome email

### How to Configure Role-Based Access

1. Go to **Admin → Users → Roles**
2. Click **"Create Role"** or edit existing
3. Enter role name and description
4. Configure permissions by module:

| Module | Permission Options |
|--------|-------------------|
| Users | View, Create, Edit, Delete |
| Events | View, Create, Edit, Delete |
| Analytics | View, Export |
| Settings | View, Edit |
| Integrations | View, Configure |

5. Set scope:
   - All data
   - Own data
   - Assigned data
6. Click **"Save Role"**

### How to Generate System Audit Report

1. Navigate to **Admin → Audit**
2. Select report type:
   | Report | Description |
   |--------|-------------|
   | User Activity | Login history, actions |
   | Data Changes | Record modifications |
   | Permission Changes | Role/permission updates |
   | System Events | Configuration changes |

3. Set date range
4. Add filters (user, action type, etc.)
5. Click **"Generate Report"**
6. Export results
7. Review for anomalies
